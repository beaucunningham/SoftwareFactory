On return, React sets activityState to plain `2` while a native-driver timing still runs on that value; with opacity detached the transition never settles, the outgoing scene stays on top, and the map takes no touches.
- Double tap (Beau 4:06pm): same cause. The first NAVIGATE commit swaps Map's activityState from the animated node to `2`; `RNSScreen.mm` `setActivityStateOrNil` (lines 326-337) ignores the nil in between while the native driver can still write the old interpolation (activityState 1), so Map isn't on top. A second press commits again and shows it. It's a race, so it only happens sometimes.
